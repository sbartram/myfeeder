<objective>
Show the "Suggested topics" section in the Interests dialog and let the user dismiss a suggestion (GAP-01, GAP-03, GAP-05; D-01..D-04, D-07, D-17; SC-1).

Task 1 (tracer) wires the API client, the query hook and the section, rendered below Topics and refetched on every open. Task 2 adds Dismiss. Task 3 marks the list stale after engagement, votes, topic create and delete, and Re-score.

The backend contract (plan 11-01 and 11-02) is fixed:
- `GET /api/interest/suggestions` returns `{items: [{articleId, title, feedTitle, interestScore}], total}`.
- `PUT /api/interest/suggestions/{articleId}/dismissal` takes no body and returns 204.

Frontend tests stub fetch, so this plan runs in parallel with the backend.

Purpose: the user sees the engaged articles no topic covers, in "surprise" order, and can clear the ones they don't care about.
Output: API client entries, two hooks and three invalidations, the `SuggestedTopics` section with styles, and the tests.
</objective>
