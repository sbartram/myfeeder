<objective>
Give the profile and the topic rubric their REST surface: validated per-item saves, the version rules, and the single cold-start predicate.

Purpose: INT-01 and INT-02 are server-enforced product rules (≤2,000 characters, ≤25 topics, weight −50..+50, default +20) that must hold for any client. D-08 wants per-item saves with stable ids. D-05 wants one server-side cold-start predicate that the status endpoint (plan 03-04) and the Phase 4 scorer both reuse.

Output: `InterestService`, `InterestController` (profile + topics routes), two request records, an end-to-end integration test, a Mockito service test and a WebMvc controller test.
