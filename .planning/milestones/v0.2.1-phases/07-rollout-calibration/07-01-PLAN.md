Make the badge tier thresholds server config and serve them on `GET /api/interest/status` (D-13, OPS-02). Today the thresholds are hardcoded in the frontend. Output: `MyfeederProperties.Interest.Blend.Tiers`, `service/TierThresholds`, `InterestStatus.tiers`, the yaml keys in both `application.yaml` files, and tests.
</objective>
