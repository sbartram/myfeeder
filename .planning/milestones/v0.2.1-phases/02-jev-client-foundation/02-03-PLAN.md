<objective>
Make Jev calls resilient with exactly one retry layer (JEV-02, SC3). Put `@CircuitBreaker("jev")` + `@Retry("jev")` on JevApiClientImpl.judge, add the jev resilience4j instances (D-09 plus the locked ignore/retry lists), honor 429 Retry-After with a capped interval function (D-07), and prove against a real-socket stub that everything works through the AOP proxy. That means transient failures are retried and open the breaker, per-article 400/422 errors do neither, a bad key opens it (D-06), and typed exceptions come through unchanged (D-08).

So every piece here has a test that fails if the wiring breaks, starting with `AopUtils.isAopProxy`. Phase 4's worker relies on these exact exception types and breaker semantics to decide which failures burn an article's attempts.

Output: annotations on judge, jev blocks in both YAML files, the `jevRetryInterval` customizer, interval unit tests in TypeSafeConfigTest, and JevResilienceTest (Docker-free, a JDK HttpServer stub).
