<objective>
Deliver the generic Jev call the later phases consume. JevApiClient.judge(state, questions) returns the app-owned JevJudgment, whose model id comes from the response (JEV-03). A keyless app refuses the call with JevNotConfiguredException and never touches the network (JEV-01). The state/answer contract (D-04) and typed errors are pinned by offline wire tests, and a gated live smoke test proves SC2 against the real API.

Purpose: Phase 3's topic preview and Phase 4's scorer both call judge() as-is (D-01). JevJudgment is the shape Phases 3-5 store and read (D-02, rated costly), so its field set and "model comes from the response" rule are fixed and tested here. Resilience (the proxy, retry and breaker) is layered onto this same method in plan 02-03 without changing its signature.

Output: four main classes in org.bartram.myfeeder.integration, JevApiClientImplTest (offline, MockRestServiceServer), and JevLiveSmokeTest (skipped by default, plus a human-check for the user to run it with their key).

Storing that id with every score is the other half of JEV-03 and is owned by Phase 4 (ROADMAP Phase 4 SC1 "the model id", SCOR-03 "model"). No table, column or repository is added here; V6 ships in Phase 3.
