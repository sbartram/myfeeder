<objective>
Let the user turn a suggestion into a topic (GAP-02, GAP-05; D-12, D-14..D-16, D-18; SC-3). Create topic adds a prefilled +20 draft, carrying the article's id, to the already-open dialog. While the draft is unsaved, the suggestion reads "Draft added". Saving sends `sourceArticleId`, which the server (plan 11-02) records atomically as TOPIC_CREATED, and the suggestion disappears.

The reading-pane "Create topic from article" path sends `sourceArticleId` too, so there is one draft path. Plan 11-02 has already put the backend contract in place.

Task 1 (tracer) wires Create topic, draft, Save, POST with the source, and suggestion gone. Task 2 adds the "Draft added" state, Discard, the at-max rule and the 500-character cut. Task 3 threads the source through the reading pane, documents the UI in CLAUDE.md and runs the phase gate.

Purpose: closes the loop: an engaged article no topic covers becomes a topic in two clicks plus a name.
Output: `addDraft(draft?)`, the source on drafts and create requests, the suggestion row's Create topic, Draft added and at-max states, the FeedbackNotice change, tests and docs.
</objective>
