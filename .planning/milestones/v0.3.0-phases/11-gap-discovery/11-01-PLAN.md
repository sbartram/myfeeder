<objective>
Serve the "Suggested topics" list from the backend (GAP-01, GAP-04, GAP-05; D-03, D-05..D-11). `GET /api/interest/suggestions` returns the engaged, SCORED, unvoted, undismissed articles whose best noul is below the near-miss constant, ordered by badge ascending ("surprise" order), capped at 10, with a total. The list works in two steps: a new `TopicSuggestionStore` runs the D-08 predicate, and the existing `InterestScoreQueries.displayScores` supplies the badge. `InterestScoreQueries` and the replay are not touched. Nothing calls Jev.

Task 1 (tracer) wires store → service → controller → HTTP and proves it over MockMvc against Testcontainers Postgres. Task 2 proves every predicate, window and ordering edge test-first. Task 3 commits the near-miss constant to yaml with startup validation.

Purpose: the backend half of gap discovery. The frontend (plan 11-03) consumes exactly this contract.
Output: four new main classes, one modified properties class, two yaml literals, and four test classes (three new, one extended).
</objective>
